# SAP Fiori Service Desk Monitor

**Portfolio lab project.** Responsive SAPUI5 worklist for monitoring incidents and SLA consumption.

## What it demonstrates

- SAP Fiori `DynamicPage`
- XML Views, controller and formatter
- OData V2 with local MockServer
- Search and responsive table
- Status semantics with `ObjectStatus`
- Simple state update
- QUnit formatter tests
- UI5 CLI build

## Run

```bash
npm install
npm start
```

## Resumo

Monitor de chamados com prioridade, responsável, consumo do SLA e ação de resolução.
